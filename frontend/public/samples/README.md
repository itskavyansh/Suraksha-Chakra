# Sample Test Images for Suraksha Chakra

The application supports testing the classifier using 8 sample images located in this directory:
1. `needle.jpg` - Hypodermic needle / syringe (Category: sharps)
2. `broken-glass.jpg` - Broken glass shards / bottles (Category: glass)
3. `battery.jpg` - Lithium-ion or mobile battery cell (Category: batteries)
4. `chemical-can.jpg` - Chemical container / pesticide bottle (Category: chemicals)
5. `medical.jpg` - Medical waste / bandages / biohazard (Category: medical)
6. `bottle.jpg` - Plastic beverage bottle (Category: general)
7. `cardboard.jpg` - Corrugated cardboard box (Category: general)
8. `unknown-item.jpg` - Unidentified or ambiguous waste item (Category: unknown)

Format requirements:
- Maximum dimensions: 800px wide JPEG
- Free-licensed (Creative Commons / Unsplash / Pexels) or self-captured photos only
- Attribution records must be documented in CREDITS.md
