# Sample Images for Suraksha Chakra Scan Feature

Place the following 8 JPEG files in this directory before deploying:

| Filename | Subject | Suggested size |
|---|---|---|
| `needle.jpg` | Needle or syringe | 800 × 600 px |
| `broken-glass.jpg` | Broken glass fragments | 800 × 600 px |
| `battery.jpg` | Battery (AA/Li-ion cell) | 800 × 600 px |
| `chemical-can.jpg` | Chemical container or paint can | 800 × 600 px |
| `medical.jpg` | Medical waste bag or IV bag | 800 × 600 px |
| `bottle.jpg` | Plastic bottle | 800 × 600 px |
| `cardboard.jpg` | Flattened cardboard | 800 × 600 px |
| `unknown-item.jpg` | Unidentified object | 800 × 600 px |

## Licensing

All images must be either:
- Free-licensed (CC0 / Unsplash / Pexels), or
- Self-taken photographs

**The app works without these files.** If a thumbnail fails to load, a placeholder icon is shown and the tap still triggers the mock classifier correctly using the filename as a hint.
