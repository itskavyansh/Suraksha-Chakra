# Suraksha Chakra

**Suraksha Chakra** is a mobile-first Progressive Web App designed for informal waste workers in India — ragpickers, kabadiwalas, and collection workers. It provides AI-powered hazard detection from phone camera photos, multilingual safety guidance (Hindi & English), training modules, job listings, a recycler directory, earnings tracking, and a worker profile — all in a single installable app that works on any smartphone.

## Run Instructions

```bash
cd frontend
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.

To build for production:

```bash
npm run build
npm run preview
```
